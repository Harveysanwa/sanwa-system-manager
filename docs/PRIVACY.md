# 隐私与安全声明（Privacy & Security）

> 一句话：**Sanwa 系统管理器是纯本机工具。仓库里没有任何个人数据；运行时的数据只留在你自己的电脑上，默认不联网、不上传、不统计。**

本文档适用于本仓库（公开的脱敏发行版）以及由它启动的本地服务。最后更新：v1.5.0。

---

## 1. 仓库脱敏声明

本仓库是面向 GitHub 公开的**脱敏发行版**，发布前经过逐文件检查。仓库中**不包含**：

| 类别 | 说明 |
|---|---|
| 个人身份 | 任何姓名、完整身份证号、手机号、邮箱、账号密码 |
| 机器信息 | 真实 Windows 用户名、计算机名、SID、域账号 |
| 真实路径 | 含用户名的绝对路径（如 `%USERPROFILE%` 之外的真实值）、本机 AI 目录、模型目录 |
| 位置信息 | 城市、地理位置、经纬度、IP 归属地 |
| 游戏库存 | 本机实际安装的游戏清单、Steam / WeGame 库路径、appid / 游戏数量截图 |
| 截图 | **任何**真实界面截图；README 中的视觉素材均为手绘矢量图（`docs/assets/banner.svg`）或 ASCII 图 |
| 日志与缓存 | `logs/`、`tmp/`、`data/profile.json`、`data/games.json`、天气缓存、背景图等运行时产物 |
| 凭据 | 任何 Token、Cookie、API Key、代理地址、内网地址 |

仓库中的路径与账号一律使用占位符，例如：

- `%USERPROFILE%` —— 当前用户目录
- `%APPDATA%` / `%LOCALAPPDATA%` —— 配置与本地数据目录
- `%SYSTEMDRIVE%` —— 系统盘
- `%SANWA_HOME%` —— 本仓库所在目录（用户自定义）
- `%SANWA_AI_ROOT%`、`%SANWA_MODELS_ROOT%` —— 可选的 AI 程序 / 模型目录
- `%USERPROFILE%\Desktop`、`D:\Games\...` —— 示例路径，需自行替换

示例配置（`data/*.example`）中的工具路径、城市、游戏库 roots 均为**占位值或可配置项**，不含任何真实值。

### 发布前自检

仓库自带脱敏扫描脚本，维护者与贡献者都可以运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\check-privacy.ps1
# PASS - 0 hits   → 可以发布
# FAIL - N hit(s) → 禁止发布，按提示修正后重跑
```

扫描覆盖 `.md` / `.js` / `.json` / `.ps1` / `.cmd` / `.html` / `.svg` 等文本文件，检查真实用户名、机器名、SID、身份证、城市、绝对 AI 目录、邮箱、手机号等模式，并允许文档中的占位符白名单。**新贡献的 PR 也必须通过该扫描。**

## 2. 运行时数据只在本机

控制中心启动后，所有数据都在本仓库目录下（或你指定的数据目录），不会上传：

| 文件 / 目录 | 内容 | 是否含个人信息 | 处理建议 |
|---|---|---|---|
| `data/tools.json` | 工具卡片、路径、模式定义 | 可能含本机路径 | 已在 `.gitignore`，勿提交 |
| `data/profile.json` | 姓名、生日、**脱敏**身份证、性别、星名编号 | **是（脱敏）** | 仅本机；可随时删除重置 |
| `data/preferences.json` | 界面主题等偏好 | 否 | 可提交前删除 |
| `data/backgrounds/` | 你上传的自定义背景图 | 可能含内容 | 已在 `.gitignore` |
| `data/games.json` | 游戏扫描结果（路径、程序名） | 可能含本机路径 | 已在 `.gitignore`，勿提交 |
| `data/fortune/preferences.json` | 天气城市偏好 | 可能是你的城市 | 仅本机 |
| `data/fortune/weather-cache.json` | 天气缓存 | 否 | 可随时删除 |
| `data/mode-state.json`、`data/mode-preferences.json` | 模式状态与 AI 选择记忆 | 否（工具 id） | 可删除 |
| `data/pids/`、`data/hub.pid` | 由本服务启动的进程 PID 记录 | 否 | 运行期文件 |
| `logs/` | 运行日志（启动 / 停止 / 模式切换记录） | 可能含本机路径与进程名 | 已在 `.gitignore`，**请勿公开粘贴未脱敏日志** |

这些文件全部位于本机磁盘，由本地 Node.js 进程读写。**控制中心没有云端服务、没有账号体系、没有数据上传接口。**

## 3. 身份证与生日门禁：只在本机、只存脱敏字段

生日门禁是为了在打开控制中心时显示「生日倒计时 / 生日礼花 / 以你命名一颗星」，实现方式是：

1. **浏览器端**完成 18 位身份证的格式与校验位校验、生日解析、性别解析；
2. 浏览器端把身份证**脱敏**为形如 `1101**********1234` 的字符串；
3. 请求 `POST /api/profile` 只提交 `name`、`birth`、`idMasked`、`gender`（可选 `star`）；
4. 服务端**只保存上述脱敏字段**，即使前端误传完整身份证也会被丢弃（见 `server.js` 的 `apiProfilePost` 字段过滤）；
5. 完整身份证**不写入日志、不落盘、不上传**。

需要如实说明的边界：

- `data/profile.json` 以**明文 JSON** 保存在本机磁盘（内容为姓名、生日、脱敏身份证、星名编号），**未做磁盘加密**。如果你的电脑多人共用或可能被他人接触，请自行评估是否启用；不需要该功能时可直接不填写，或删除该文件。
- 姓名与生日本身属于个人信息，虽然只在本地，仍建议不要在使用共享电脑时录入。
- 生日礼花与倒计时仅在前端计算与展示，不发送给任何第三方。

**重置方法**：关闭控制中心 → 删除 `data/profile.json` → 重新打开页面，即恢复首次门禁。

## 4. 无遥测、无 CDN、无 npm 依赖

- **无遥测**：不包含任何统计、埋点、崩溃上报、广告 SDK；不生成设备指纹；不向任何服务器发送「使用了什么工具 / 看了什么页面」。
- **无 npm 依赖**：服务端只用 Node.js 标准库；`lib/fortune/vendor/` 中的农历与汉字库是随仓库分发的 vendored 文件（MIT 许可，见 `THIRD_PARTY_NOTICES.md`），运行时不执行 `npm install`。
- **无 CDN**：界面不引用任何外部 CSS / JS / 字体 / 图标库；界面文件由 `scripts/build-ui.js` 生成后本地提供。
- **无账号**：不需要登录、不需要联网授权。

## 5. 唯一的外联：天气

运行时唯一主动发起的外部网络请求是天气数据：

| 数据源 | 协议 | 用途 |
|---|---|---|
| `wttr.in` | HTTPS | 实时天气 + 3 日预报 + 自动定位（基于出口 IP，可能不精确） |
| `api.open-meteo.com` | HTTP | 7 日预报（主源） |
| `www.weather.com.cn` | HTTP | 7 日预报兜底 |

说明：

- 请求参数只包含**城市名或经纬度**（用于查询天气），不包含姓名、身份证、机器信息、工具清单等任何其他数据。
- 若你在设置中把城市留空并开启自动定位，定位由天气服务根据你的出口 IP 推断，控制中心本身不调用系统定位。
- 若你的网络环境不允许这些域名，天气面板会优雅降级（显示缓存或提示不可用），不影响其他功能。

除此之外：点击工具卡片的「打开」会打开你配置的本地程序或网址；这些是你自己的配置行为，不属于控制中心的数据上传。

## 6. 安全边界

- **仅监听本机**：默认 `127.0.0.1:9900`，不监听 `0.0.0.0`，不对外网开放。
- **启动白名单**：`POST /api/launch` 只接受 `data/tools.json` 中存在的工具 `id`，并只执行 `scripts/<id>.ps1` 预置脚本；请求体中的任意路径 / 命令 / 参数一律忽略。
- **停止归属校验**：`POST /api/stop` 只停止由本服务启动（PID 文件 + 启动时间 + 可执行路径三重校验）的进程；不会停止用户自己打开的软件。
- **进程保护**：模式引擎保护 DeepSeek Harness、控制中心自身、`node.exe`、系统进程、Steam 与雷神加速器；按「进程名 + 可执行文件路径」双条件匹配，不使用 `taskkill /IM` 全域结束进程。
- **不静默提权**：需要管理员权限的辅助脚本（如 Steam 断网）只生成 / 提示路径，由用户**手动以管理员身份运行**；服务本身不请求提权、不修改系统服务。
- **无任意命令执行接口**：没有可传入 shell 命令的 API；新增工具必须改配置与脚本（见 `docs/CONTRIBUTING.md`）。

### 使用建议

1. **不要把控制中心暴露到公网**：不要修改为 `0.0.0.0`，不要在路由器上做端口映射。如确需远程访问，请自行加 VPN 或带鉴权的反向代理，并理解风险。
2. **不要复用系统管理员账号跑日常任务**：需要管理员辅助脚本时再单独提权。
3. **定期检查自启快捷方式**：`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\` 下只应存在你自己创建的控制中心快捷方式；可在页面设置里一键关闭。
4. **谨慎运行社区脚本**：Fork / 二创项目可能改动了安全边界，运行前先读脚本。
5. **断网辅助脚本可逆**：Steam 断网使用防火墙规则 `Sanwa-Steam-Block`，用 `tools/steam-net-on.ps1` 恢复；如忘记恢复，可在「高级安全 Windows Defender 防火墙 → 出站规则」中删除该规则。
6. **日志脱敏**：向 Issue 粘贴日志前，请删除其中的用户名、路径、城市、进程名中的隐私片段。
